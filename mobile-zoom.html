如何保证“缩放不跳”？

双指开始时，不只记录初始距离，还记录两指中点正下方的图片坐标 p。移动时每帧用新的中点和倍率反推位移，让同一个图片点始终留在中点下：

p = (m - t) / s       // 开始：中点下的图片坐标
s' = clamp(s₀ × d / d₀, 1, 4)
t' = m' - p × s'      // 每帧：反推新位移

其中 m 是容器内中点，t 是位移，s 是倍率。第二根手指按下、松开其中一指和 touchcancel 时都会重置基准，避免沿用上轮残留数据。

边界与旋转

  • 位移限制在 0 与容器尺寸 × (1−scale) 之间，图片始终覆盖查看区。
  • scale 回到 1x 时 translate 强制归零，图片自动居中且不能拖动。
  • 双击通过 0.25s CSS transition 平滑切换，不叠加原生页面双击缩放。
  • resize 时记录画面中心的归一化图片坐标，按新容器尺寸恢复并再次限制边界。
